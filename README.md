# ระบบบันทึกภาระงาน P4P กลุ่มงานเภสัชกรรม

เว็บแอปสำหรับบันทึกจำนวนงานรายวัน คำนวณคะแนน และติดตามเป้าหมายรายบุคคลของกลุ่มงานเภสัชกรรม โรงพยาบาลสมเด็จพระยุพราชสว่างแดนดิน

## ความสามารถ

- บันทึกงานใน Matrix รายวันตามเดือนที่เลือก
- ตั้งค่าประเภทงานและคะแนนต่อ 1 งานได้เอง
- เพิ่มบุคลากรและเลือกตำแหน่งตามเกณฑ์คะแนนรายเดือน
- แสดงคะแนนรวม ความคืบหน้า และสถานะผ่านเป้าหมายรายบุคคล
- บันทึกข้อมูลอัตโนมัติใน `localStorage` แยกตามงวดเดือนและเบราว์เซอร์
- ส่งออกไฟล์ Excel ซึ่งมีชีตสรุปภาพรวมและ Matrix รายวัน

## เกณฑ์คะแนนประกันรายเดือน

| ตำแหน่ง | เป้าหมาย |
| --- | ---: |
| เภสัชกร | 1,440 |
| เจ้าพนักงานเภสัชกรรม | 960 |
| พนักงานประจำห้องยา | 600 |

## เริ่มใช้งาน

เปิด `index.html` ในเว็บเบราว์เซอร์ หรือเผยแพร่เป็น static site ได้โดยไม่ต้องติดตั้ง build tools

เพิ่มบุคลากรและประเภทงานก่อนเริ่มกรอก Matrix คะแนนของแต่ละประเภทงานตั้งค่าได้ตามเกณฑ์ของหน่วยงาน ตัวแอปไม่ได้กำหนดคะแนนต่องานล่วงหน้า เพราะรายละเอียดคะแนนรายกิจกรรมไม่ได้อยู่ในข้อกำหนดที่ให้มา

## หมายเหตุ

ข้อมูลอยู่ในเบราว์เซอร์และอุปกรณ์ที่ใช้กรอกเท่านั้น การล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์อาจทำให้ข้อมูลหาย ควรส่งออก Excel เพื่อสำรองข้อมูลเป็นระยะ การโหลด Tailwind CSS, Lucide Icons, SheetJS และฟอนต์ Sarabun ต้องใช้อินเทอร์เน็ต
